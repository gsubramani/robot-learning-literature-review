# How to use skills in this repo
This is a tool that helps you quickly understand papers using a coding assistant. The skills in the .agents folder help with research. The ai-task and research-md skills will save their artifacts in the `.ai/research/` folder


# Organization
The repo is meant to grow organically. At the moment use the following guidelines

`.ai/` : this is where the agent artifacts should go.
`documents/` : any fully featured content in a document format would go in this folder.
`note/` : any human written notes can go inside here. This is a space to share information between users and high level note taking.
